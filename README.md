# Ogre Now

When the Krol'dok Battlegear (5/5) bonus turns you into an ogre (20 stacks of Ogre Dominance), you yell **IT'S ALL OGRE NOW**.

The game hides your buffs from addons in combat, so Ogre Now also watches for your character model to change into the ogre.

Outside instances, the game only allows a yell on a key press or click. The yell then goes out on the next key you press. If you press nothing for 3 seconds, a button shows up to click.

## Commands

- `/ogre`: show what it is watching
- `/ogre scan`: list your buffs and their stacks (out of combat)
- `/ogre stack <count> <buff name>`: change the trigger
- `/ogre test`: test the yell
- `/ogre debug`: show model changes in chat
